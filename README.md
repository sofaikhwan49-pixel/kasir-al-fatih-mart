# 🛒 Kasir Al-Fatih Mart

Aplikasi kasir berbasis web menggunakan PHP Native dan MySQL.

## ✨ Fitur
- Login Admin
- Dashboard Kasir
- Input Penjualan
- Keranjang Belanja
- Inventori Barang
- Riwayat Transaksi
- Logout

## 🛠 Teknologi
- PHP Native
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap

## 📂 Struktur Folder

```
config/
controller/
model/
view/
index.php
content.php
menu.php
```

## 🚀 Cara Menjalankan
1. Clone repository.
2. Import database ke MySQL.
3. Atur koneksi database pada `config/Database.php`.
4. Jalankan menggunakan XAMPP atau Laragon.
